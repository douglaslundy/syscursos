# Prompt 10 — Review final

Leia:

- `AGENTS.md`
- `docs/PROJECT_CONTEXT.md`
- `prompts/00_MASTER_INSTRUCTIONS.md`

Faça review final completo do projeto.

Verifique:

- arquitetura;
- segurança;
- autorização;
- RLS;
- validação;
- performance;
- acessibilidade;
- responsividade;
- duplicações;
- tipagem;
- código morto;
- dependências desnecessárias;
- organização de pastas;
- qualidade dos testes;
- build de produção;
- proteção contra acesso horizontal;
- validade das matrículas;
- separação entre admin e aluno.

Corrija problemas encontrados.

Depois gere:

- relatório final em `docs/REVIEW.md`;
- lista de pendências reais;
- recomendações para próxima versão;
- confirmação dos comandos executados e resultados.

Trabalhe em modo autônomo. Não peça confirmação para decisões técnicas triviais.
