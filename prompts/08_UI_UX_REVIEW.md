# Prompt 8 — UI/UX e responsividade

Leia:

- `AGENTS.md`
- `docs/PROJECT_CONTEXT.md`
- `docs/UI_UX.md`
- `prompts/00_MASTER_INSTRUCTIONS.md`

Revise e melhore a interface.

Objetivo:

Criar uma interface moderna de área de membros, original e responsiva.

Implementar ou revisar:

- sidebar desktop;
- bottom navigation mobile;
- cards de curso;
- páginas com boa hierarquia visual;
- skeleton loading;
- estados vazios;
- estados de erro;
- responsividade;
- acessibilidade;
- contraste adequado;
- navegação clara;
- consistência visual entre admin e aluno.

Proibido:

- copiar Hotmart;
- usar logo Hotmart;
- usar textos Hotmart;
- usar assets Hotmart;
- replicar identidade visual proprietária.

Ao finalizar:

- revisar acessibilidade;
- rodar lint;
- rodar typecheck;
- rodar build;
- atualizar `docs/UI_UX.md`;
- atualizar `docs/REVIEW.md`;
- registrar decisões em `docs/DECISIONS.md`.

Trabalhe em modo autônomo. Não peça confirmação para decisões técnicas triviais.
